# H14: DelegateTree: revocation removed independent grants but retained descendants

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Delegations form an acyclic forest with existing parents and unchanged resource along a chain. A grant is effective only if neither it nor any ancestor is revoked. Count effective grant nodes per (user,resource), one access row if count>0. Revocation on one path does not remove an independent root/path. work contains all affected users, including descendants. The fixed patch refreshes only user IDs in work for access, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A flat revoke removed all access for one user but missed a grandchild of the revoked root.
- delegations -> access; work -> access

Immutable tables: delegations, work.
Writable projections: access.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE delegations(id TEXT PRIMARY KEY,parent TEXT,user TEXT,resource TEXT,revoked INTEGER);
CREATE TABLE access(user TEXT,resource TEXT,paths INTEGER,PRIMARY KEY(user,resource));
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM access WHERE user IN (SELECT entity FROM work); INSERT INTO access SELECT * FROM (WITH RECURSIVE live(id,user,resource) AS (SELECT id,user,resource FROM delegations WHERE parent IS NULL AND revoked=0 UNION ALL SELECT d.id,d.user,d.resource FROM delegations d JOIN live l ON d.parent=l.id WHERE d.revoked=0) SELECT user,resource,COUNT(*) FROM live GROUP BY user,resource) WHERE user IN (SELECT entity FROM work);
```

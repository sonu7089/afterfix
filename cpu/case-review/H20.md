## Business rules

Days are consecutive integer slots per entity, covered by at least one change. A change applies to half-open [lo,hi). For each day choose the highest-seq covering change; later explicit overrides survive retroactive corrections with lower seq. Materialize maximal contiguous intervals of equal value, coalescing adjacent equal values but never across gaps with another value. Store half-open endpoints. seq is unique per entity. The fixed patch refreshes only entity IDs in work for intervals, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A historical correction replaced an entire interval without splitting around a later override.
- days + changes -> intervals; work -> intervals

Immutable tables: days, changes, work.
Writable projections: intervals.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE days(entity TEXT,day INTEGER,PRIMARY KEY(entity,day));
CREATE TABLE changes(id TEXT PRIMARY KEY,entity TEXT,lo INTEGER,hi INTEGER,seq INTEGER,value INTEGER);
CREATE TABLE intervals(entity TEXT,lo INTEGER,hi INTEGER,value INTEGER,PRIMARY KEY(entity,lo));
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM intervals WHERE entity IN (SELECT entity FROM work); INSERT INTO intervals SELECT * FROM (WITH v AS (SELECT d.entity,d.day,(SELECT value FROM changes c WHERE c.entity=d.entity AND c.lo<=d.day AND d.day<c.hi ORDER BY seq DESC LIMIT 1) AS value FROM days d), g AS (SELECT *,day-ROW_NUMBER() OVER(PARTITION BY entity,value ORDER BY day) AS grp FROM v) SELECT entity,MIN(day),MAX(day)+1,value FROM g GROUP BY entity,value,grp) WHERE entity IN (SELECT entity FROM work);
```

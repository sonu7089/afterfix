This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

versions combines backup versions and later authoritative edits. Select highest revision per ID, then exclude every record whose subject has an authoritative erasure. Subject is stable across versions. Erasure is by subject, not by subtree. Preserve nonerased descendants but set their parent NULL if that parent is absent after filtering. Retain their payloads and latest edits. This is a synthetic restore projection; immutable backup evidence remains an audit input, not a production erasure implementation. The fixed patch refreshes only id IDs in work for restored, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A snapshot restore resurrected an erased subject; a subtree delete would also lose a different subject child.
- versions + erasures -> restored; work -> restored

Immutable tables: versions, erasures, work.
Writable projections: restored.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE versions(id TEXT,revision INTEGER,subject TEXT,parent TEXT,payload TEXT,PRIMARY KEY(id,revision));
CREATE TABLE erasures(subject TEXT PRIMARY KEY);
CREATE TABLE restored(id TEXT PRIMARY KEY,revision INTEGER,parent TEXT,payload TEXT);
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM restored WHERE id IN (SELECT entity FROM work); INSERT INTO restored SELECT * FROM (WITH latest AS (SELECT v.* FROM versions v WHERE NOT EXISTS(SELECT 1 FROM versions x WHERE x.id=v.id AND x.revision>v.revision)), safe AS (SELECT * FROM latest l WHERE NOT EXISTS(SELECT 1 FROM erasures e WHERE e.subject=l.subject)) SELECT s.id,s.revision,CASE WHEN EXISTS(SELECT 1 FROM safe p WHERE p.id=s.parent) THEN s.parent ELSE NULL END,s.payload FROM safe s) WHERE id IN (SELECT entity FROM work);
```

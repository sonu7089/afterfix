## Business rules

Original shipments reserve ordered minus shipped, regardless of returns. net_delivered counts original shipped units minus accepted returns on those shipments. Every accepted return requests the same quantity of replacement; replacement_due subtracts replacements already shipped for that return. Replacements are tracked separately and are not original shipments. Rejected returns do nothing. Valid quantities never over-return or over-replace. The fixed patch refreshes only line IDs in work for line_state, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- An order-level refund freed still-unshipped allocations; replay also forgot an already sent replacement.
- lines + shipments + returns + replacements -> line_state; work -> line_state

Immutable tables: lines, shipments, returns, replacements, work.
Writable projections: line_state.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE lines(id TEXT PRIMARY KEY,ordered INTEGER);
CREATE TABLE shipments(id TEXT PRIMARY KEY,line TEXT,qty INTEGER);
CREATE TABLE returns(id TEXT PRIMARY KEY,shipment TEXT,qty INTEGER,accepted INTEGER);
CREATE TABLE replacements(return_id TEXT PRIMARY KEY,shipped INTEGER);
CREATE TABLE line_state(line TEXT PRIMARY KEY,reserved INTEGER,net_delivered INTEGER,replacement_due INTEGER);
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM line_state WHERE line IN (SELECT entity FROM work); INSERT INTO line_state SELECT * FROM (SELECT l.id AS line,l.ordered-COALESCE((SELECT SUM(qty) FROM shipments s WHERE s.line=l.id),0),COALESCE((SELECT SUM(qty) FROM shipments s WHERE s.line=l.id),0)-COALESCE((SELECT SUM(r.qty) FROM returns r JOIN shipments s ON s.id=r.shipment WHERE s.line=l.id AND r.accepted=1),0),COALESCE((SELECT SUM(r.qty-COALESCE(p.shipped,0)) FROM returns r JOIN shipments s ON s.id=r.shipment LEFT JOIN replacements p ON p.return_id=r.id WHERE s.line=l.id AND r.accepted=1),0) FROM lines l) WHERE line IN (SELECT entity FROM work);
```

# H23: FillMark: a processing cursor falsely certified event-time completeness

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: All evaluated streams have partitions. Empty-stream SQL and oracle outputs differ in a separate probe.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Partition slots are contiguous positive integers starting at one, with positive expected accepted-event counts. complete_through is the largest contiguous prefix whose slots each have exactly expected accepted events; zero when slot 1 is incomplete. accepted_count includes ALL accepted events, even beyond gaps and late arrivals. Event IDs are unique. progress.processed is processing progress, not evidence of event-time completeness. Rejected events never count. The fixed patch refreshes only stream IDs in work for watermarks, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A high processing cursor masked a gap in the first event-time partition; accepted late events beyond the gap must survive.
- streams + partitions + events -> watermarks; work -> watermarks

Immutable tables: streams, partitions, events, progress, work.
Writable projections: watermarks.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE streams(id TEXT PRIMARY KEY);
CREATE TABLE partitions(stream TEXT,slot INTEGER,expected INTEGER,PRIMARY KEY(stream,slot));
CREATE TABLE events(id TEXT PRIMARY KEY,stream TEXT,slot INTEGER,accepted INTEGER,arrival INTEGER);
CREATE TABLE progress(stream TEXT PRIMARY KEY,processed INTEGER);
CREATE TABLE watermarks(stream TEXT PRIMARY KEY,complete_through INTEGER,accepted_count INTEGER);
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM watermarks WHERE stream IN (SELECT entity FROM work); INSERT INTO watermarks SELECT * FROM (SELECT s.id AS stream,COALESCE((SELECT MIN(p.slot)-1 FROM partitions p WHERE p.stream=s.id AND (SELECT COUNT(*) FROM events e WHERE e.stream=p.stream AND e.slot=p.slot AND e.accepted=1)<>p.expected),(SELECT MAX(slot) FROM partitions p WHERE p.stream=s.id)),(SELECT COUNT(*) FROM events e WHERE e.stream=s.id AND e.accepted=1) FROM streams s) WHERE stream IN (SELECT entity FROM work);
```

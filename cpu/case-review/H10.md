# H10: CompactSpan: partial publication counted source and replacement ranges twice

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

slots enumerates logical record positions. coverage maps every slot to exactly one physical segment: highest generation among published segments covering its half-open [lo,hi) range. Same-generation ranges never overlap; every slot has a published covering segment. A partially published compaction supersedes only its published subranges. Staged ranges contribute nothing; retain old coverage elsewhere. The fixed patch refreshes only dataset IDs in work for coverage, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A compaction index switched the entire source range before the right replacement was published.
- slots + segments -> coverage; work -> coverage

Immutable tables: slots, segments, work.
Writable projections: coverage.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE slots(dataset TEXT,pos INTEGER,PRIMARY KEY(dataset,pos));
CREATE TABLE segments(id TEXT PRIMARY KEY,dataset TEXT,lo INTEGER,hi INTEGER,generation INTEGER,published INTEGER);
CREATE TABLE coverage(dataset TEXT,pos INTEGER,file TEXT,generation INTEGER,PRIMARY KEY(dataset,pos));
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM coverage WHERE dataset IN (SELECT entity FROM work); INSERT INTO coverage SELECT * FROM (SELECT s.dataset,s.pos,f.id,f.generation FROM slots s JOIN segments f ON f.dataset=s.dataset AND s.pos>=f.lo AND s.pos<f.hi AND f.published=1 WHERE NOT EXISTS(SELECT 1 FROM segments g WHERE g.dataset=s.dataset AND s.pos>=g.lo AND s.pos<g.hi AND g.published=1 AND g.generation>f.generation)) WHERE dataset IN (SELECT entity FROM work);
```

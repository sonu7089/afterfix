# H06: StockBridge: partial transfer receipts were credited as full deliveries

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Accepted transfers debit their full quantity from source. Credit destination only for accepted receipt quantities of accepted transfers; ignore rejected receipts and all evidence for rejected transfers. Receipt IDs identify distinct parts; accepted receipt sum never exceeds quantity. in_transit=debit-credit. Stock equals opening minus outgoing debits plus incoming credits. Stock plus all in_transit conserves opening inventory. The fixed patch refreshes only id IDs in work for transfer_state, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- Transfer finalization assumed shipment meant full receipt and honored a receipt for a rejected transfer.
- transfers + receipts -> transfer_state; warehouses + transfers + transfer_state -> stock; work -> transfer_state

Immutable tables: warehouses, transfers, receipts, work.
Writable projections: transfer_state, stock.
Full rebuilding is allowed. No append-only requirement is present.

## Supplied application patch

```sql
DELETE FROM transfer_state WHERE id IN (SELECT entity FROM work); INSERT INTO transfer_state SELECT * FROM (SELECT t.id,t.qty*t.accepted,CASE WHEN t.accepted=1 THEN COALESCE((SELECT SUM(qty) FROM receipts r WHERE r.transfer=t.id AND r.accepted=1),0) ELSE 0 END,t.qty*t.accepted-(CASE WHEN t.accepted=1 THEN COALESCE((SELECT SUM(qty) FROM receipts r WHERE r.transfer=t.id AND r.accepted=1),0) ELSE 0 END) FROM transfers t) WHERE id IN (SELECT entity FROM work);DELETE FROM stock; INSERT INTO stock SELECT w.id,w.opening-COALESCE((SELECT SUM(s.debit) FROM transfer_state s JOIN transfers t ON t.id=s.id WHERE t.source=w.id),0)+COALESCE((SELECT SUM(s.credit) FROM transfer_state s JOIN transfers t ON t.id=s.id WHERE t.destination=w.id),0) FROM warehouses w;
```

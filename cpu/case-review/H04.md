# H04: FenceRun: a retired lease owner published a late completion

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: Conflicting valid completions with the same sequence have no specified tie-break; none occur in evaluated fixtures.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

One result per current lease. A completion is valid only when job, generation, fencing token AND owner match the current lease exactly. Choose the highest seq among valid completions: done and its value. With none: pending and value zero. seq breaks ties within a lease; late arrival does not grant authority to an old owner or token. The fixed patch refreshes only job IDs in work for job_results, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- Late stale-owner output replaced the new owner result. Another job has only a wrong-token completion.
- leases + completions -> job_results; work -> job_results

Immutable tables: leases, completions, work.
Writable projections: job_results.
Full rebuilding is allowed. No append-only requirement is present.

## Supplied application patch

```sql
DELETE FROM job_results WHERE job IN (SELECT entity FROM work); INSERT INTO job_results SELECT * FROM (SELECT l.job,CASE WHEN EXISTS(SELECT 1 FROM completions c WHERE c.job=l.job AND c.generation=l.generation AND c.fence=l.fence AND c.owner=l.owner) THEN 'done' ELSE 'pending' END,COALESCE((SELECT value FROM completions c WHERE c.job=l.job AND c.generation=l.generation AND c.fence=l.fence AND c.owner=l.owner ORDER BY seq DESC LIMIT 1),0) FROM leases l) WHERE job IN (SELECT entity FROM work);
```

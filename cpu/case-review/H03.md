# H03: SagaDock: compensation intents included unfinished child steps

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

compensation is a rebuildable intent/status projection, not an external side-effect log. Include every child step. Only completed steps of canceled parents require undo: state done if an accepted undo receipt exists, otherwise pending; units equals cost. All other steps have state none and zero units. Never enqueue undo again for an acknowledged compensation. Parent changes expand work to child step IDs. The fixed patch refreshes only step IDs in work for compensation, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A saga retry generated undo intents for every child and reset an acknowledged undo.
- parents + steps + undo_receipts -> compensation; work -> compensation

Immutable tables: parents, steps, undo_receipts, work.
Writable projections: compensation.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE parents(id TEXT PRIMARY KEY,state TEXT);
CREATE TABLE steps(id TEXT PRIMARY KEY,parent TEXT,state TEXT,cost INTEGER);
CREATE TABLE undo_receipts(step TEXT PRIMARY KEY,accepted INTEGER);
CREATE TABLE compensation(step TEXT PRIMARY KEY,state TEXT,units INTEGER);
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM compensation WHERE step IN (SELECT entity FROM work); INSERT INTO compensation SELECT * FROM (SELECT s.id AS step,CASE WHEN p.state='canceled' AND s.state='completed' THEN CASE WHEN EXISTS(SELECT 1 FROM undo_receipts u WHERE u.step=s.id AND u.accepted=1) THEN 'done' ELSE 'pending' END ELSE 'none' END,CASE WHEN p.state='canceled' AND s.state='completed' THEN s.cost ELSE 0 END FROM steps s JOIN parents p ON p.id=s.parent) WHERE step IN (SELECT entity FROM work);
```

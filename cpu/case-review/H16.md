# H16: CapChain: child scopes widened beyond ancestor limits

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Capabilities form an acyclic forest. Scopes are integer bit masks (read=1, write=2, export=4). Effective scope is bitwise AND along the entire ancestor path, and expiry is the minimum along that path. Include a capability only if effective mask is nonzero and expiry>clock.now; equality is expired. A longer child expiry never extends its parent. work expands descendants of changed roots and expired paths. The fixed patch refreshes only id IDs in work for effective, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A delegator unioned scope bits and used the child expiry, extending authority beyond the root.
- clock + capabilities -> effective; work -> effective

Immutable tables: clock, capabilities, work.
Writable projections: effective.
Full rebuilding is allowed. No append-only requirement is present.

## Supplied application patch

```sql
DELETE FROM effective WHERE id IN (SELECT entity FROM work); INSERT INTO effective SELECT * FROM (WITH RECURSIVE c(id,mask,expires) AS (SELECT id,mask,expires FROM capabilities WHERE parent IS NULL UNION ALL SELECT a.id,a.mask&c.mask,MIN(a.expires,c.expires) FROM capabilities a JOIN c ON a.parent=c.id) SELECT c.id,c.mask,c.expires FROM c CROSS JOIN clock t WHERE c.mask>0 AND c.expires>t.now) WHERE id IN (SELECT entity FROM work);
```

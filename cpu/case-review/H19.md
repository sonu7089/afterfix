# H19: TierMeter: replay priced every usage event in the first tier

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: Positive units applies to use events. Reset is a zero-unit control record; this clarifies an ambiguity in the frozen wording.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Each use event receives low tier units up to the account threshold minus earlier usage since the latest reset, then high tier units for the remainder. cost=low_units*low_rate+high_units*high_rate. Process authoritative seq, not arrival. Reset starts a new cumulative period and has no charge row. Units and rates are positive; late arrivals can change earlier-period marginal allocation but not cross reset boundaries. The fixed patch refreshes only account IDs in work for charges, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- A late pre-reset event was charged at the low rate and also polluted the next period total.
- accounts + usage_events -> charges; work -> charges

Immutable tables: accounts, usage_events, work.
Writable projections: charges.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE accounts(id TEXT PRIMARY KEY,threshold INTEGER,low_rate INTEGER,high_rate INTEGER);
CREATE TABLE usage_events(id TEXT PRIMARY KEY,account TEXT,seq INTEGER,kind TEXT,units INTEGER,arrival INTEGER,UNIQUE(account,seq));
```

## Supplied application patch

```sql
DELETE FROM charges WHERE account IN (SELECT entity FROM work); INSERT INTO charges SELECT * FROM (WITH u AS (SELECT e.*,a.threshold,a.low_rate,a.high_rate,COALESCE((SELECT SUM(p.units) FROM usage_events p WHERE p.account=e.account AND p.kind='use' AND p.seq<e.seq AND p.seq>COALESCE((SELECT MAX(r.seq) FROM usage_events r WHERE r.account=e.account AND r.kind='reset' AND r.seq<e.seq),0)),0) AS prior FROM usage_events e JOIN accounts a ON a.id=e.account WHERE e.kind='use'), v AS (SELECT *,MIN(units,MAX(0,threshold-prior)) AS lo FROM u) SELECT account,id,lo,units-lo,lo*low_rate+(units-lo)*high_rate FROM v) WHERE account IN (SELECT entity FROM work);
```

# H02: InboxLane: a failed consumer transaction overwrote an accepted revision

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Each event is a full replacement value, not a delta. An event is accepted if any transaction attempt committed, even if a duplicate retry failed. Materialize the highest accepted revision for each entity; with none use initial and revision zero. Failed-only events have no effect. Later accepted replacements supersede earlier ones. The fixed patch refreshes only entity IDs in work for applied, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- An inbox rebuild read the highest seen revision before checking transaction commit.
- entities + events + attempts -> applied; work -> applied

Immutable tables: entities, events, attempts, work.
Writable projections: applied.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE entities(id TEXT PRIMARY KEY,initial INTEGER);
CREATE TABLE events(id TEXT PRIMARY KEY,entity TEXT,revision INTEGER,value INTEGER,UNIQUE(entity,revision));
CREATE TABLE attempts(id TEXT PRIMARY KEY,event TEXT,outcome TEXT);
CREATE TABLE applied(entity TEXT PRIMARY KEY,value INTEGER,revision INTEGER);
CREATE TABLE work(entity TEXT PRIMARY KEY);
```

## Supplied application patch

```sql
DELETE FROM applied WHERE entity IN (SELECT entity FROM work); INSERT INTO applied SELECT * FROM (SELECT x.id AS entity,COALESCE((SELECT value FROM events e WHERE e.entity=x.id AND EXISTS(SELECT 1 FROM attempts a WHERE a.event=e.id AND a.outcome='committed') ORDER BY revision DESC LIMIT 1),x.initial),COALESCE((SELECT MAX(revision) FROM events e WHERE e.entity=x.id AND EXISTS(SELECT 1 FROM attempts a WHERE a.event=e.id AND a.outcome='committed')),0) FROM entities x) WHERE entity IN (SELECT entity FROM work);
```

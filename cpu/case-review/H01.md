## Business rules

Every message has one outbox row. Any accepted receipt means delivered, even if a later transport retry was logged or the message was disabled. Otherwise disabled messages are canceled; otherwise any permanent receipt means failed; otherwise pending. attempts is the maximum recorded attempt number, or zero. Receipts are authoritative acknowledgements, not requests to resend. Never erase them. Reconstructing a delivered message as pending can cause duplicate delivery. The patch refreshes only message IDs in work, the immutable current change-feed batch. Historical messages are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- An outbox rehydration used the last transport outcome and lost an earlier acknowledgement.
- messages + receipts -> outbox; work -> outbox
- A disabled reminder and an unrelated delivered notice are legitimate controls. A late retry does not undo delivery.

Immutable tables: messages, receipts, work.
Writable projections: outbox.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE messages(id TEXT PRIMARY KEY,enabled INTEGER,body TEXT);
CREATE TABLE receipts(id TEXT PRIMARY KEY,message TEXT,result TEXT,attempt INTEGER);
CREATE TABLE work(entity TEXT PRIMARY KEY);
CREATE TABLE outbox(id TEXT PRIMARY KEY,state TEXT,attempts INTEGER);
```

## Supplied application patch

```sql
DELETE FROM outbox WHERE id IN (SELECT entity FROM work); INSERT INTO outbox SELECT m.id,CASE WHEN EXISTS(SELECT 1 FROM receipts r WHERE r.message=m.id AND r.result='accepted') THEN 'delivered'
WHEN m.enabled=0 THEN 'canceled' WHEN EXISTS(SELECT 1 FROM receipts r WHERE r.message=m.id AND r.result='permanent') THEN 'failed' ELSE 'pending' END,
COALESCE((SELECT MAX(attempt) FROM receipts r WHERE r.message=m.id),0) FROM messages m WHERE m.id IN (SELECT entity FROM work);
```

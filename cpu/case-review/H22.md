## Business rules

Only accepted links establish undirected equivalence. Compute transitive components, with lexicographically smallest entity ID as representative and component size as members. Keep one row for every entity including singletons. Rejected and pending candidate links do not connect components. work expands to every member of components changed by adjudication. The fixed patch refreshes only entity IDs in work for canonical, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- Candidate generation was mistaken for adjudication and a rejected bridge merged separate identities.
- entities + links -> canonical; work -> canonical

Immutable tables: entities, links, work.
Writable projections: canonical.
Full rebuilding is allowed. No append-only requirement is present.

## Supplied application patch

```sql
DELETE FROM canonical WHERE entity IN (SELECT entity FROM work); INSERT INTO canonical SELECT * FROM (WITH RECURSIVE edges(a,b) AS (SELECT a,b FROM links WHERE decision='accepted' UNION SELECT b,a FROM links WHERE decision='accepted'), reach(a,b) AS (SELECT id,id FROM entities UNION SELECT r.a,e.b FROM reach r JOIN edges e ON e.a=r.b) SELECT a AS entity,MIN(b),COUNT(*) FROM reach GROUP BY a) WHERE entity IN (SELECT entity FROM work);
```

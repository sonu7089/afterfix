## Business rules

An unexpired lease commits issued units, including consumed units. At expires<=clock.now only consumed units remain committed permanently; unused escrow returns. Sum commitments per tenant, subtract from tenant capacity and shared parent capacity. Consumption never exceeds issued; valid fixtures fit both limits. A clock tick puts all affected tenants in work. The fixed patch refreshes only tenant IDs in work for escrow, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- An expiry sweep refunded entire leases, including irrevocably consumed units.
- clock + leases + tenants -> escrow; pools + tenants + escrow -> pool_free; work -> escrow

Immutable tables: clock, pools, tenants, leases, work.
Writable projections: escrow, pool_free.
Full rebuilding is allowed. No append-only requirement is present.

## Supplied application patch

```sql
DELETE FROM escrow WHERE tenant IN (SELECT entity FROM work); INSERT INTO escrow SELECT * FROM (SELECT t.id AS tenant,COALESCE((SELECT SUM(CASE WHEN l.expires>c.now THEN l.issued ELSE l.consumed END) FROM leases l CROSS JOIN clock c WHERE l.tenant=t.id),0),t.capacity-(COALESCE((SELECT SUM(CASE WHEN l.expires>c.now THEN l.issued ELSE l.consumed END) FROM leases l CROSS JOIN clock c WHERE l.tenant=t.id),0)) FROM tenants t) WHERE tenant IN (SELECT entity FROM work);DELETE FROM pool_free; INSERT INTO pool_free SELECT p.id,p.capacity-COALESCE((SELECT SUM(e.committed) FROM escrow e JOIN tenants t ON t.id=e.tenant WHERE t.pool=p.id),0) FROM pools p;
```

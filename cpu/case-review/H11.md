# H11: EpochDesk: a migration replaced explicit NULL and later operator edits

**Review status: internal AI review complete; evaluated fixtures accepted with documented scope.**

This is not independent human validation. The historical specification below is unchanged.

Review qualification: See the full review for business-policy assumptions and production limits.

This card shows seed 0. The source generator also supplies variants 7 and 19.

## Business rules

Apply a default for the document schema epoch only when present=0. present=1 with value NULL is an explicit stored NULL, not absence. Any operator edit supersedes migration; highest seq wins even when its value is NULL. source is operator, stored, or default respectively. revision is highest edit seq or zero. Every document has exactly one matching epoch default. The fixed patch refreshes only id IDs in work for migrated, then refreshes any dependent summaries. Historical IDs are absent from work. All evidence tables including work are immutable. Listed projections are rebuildable. Recover all historical damage, preserve unrelated correct records, and leave an already healthy snapshot unchanged. Recovery and subsequent patch processing must be repeatable.

## Evidence

- COALESCE confused explicit NULL with absent fields and overwrote a later operator-cleared value.
- documents + defaults + edits -> migrated; work -> migrated

Immutable tables: documents, defaults, edits, work.
Writable projections: migrated.
Full rebuilding is allowed. No append-only requirement is present.

## Schema and column order

```sql
CREATE TABLE documents(id TEXT PRIMARY KEY,epoch INTEGER,present INTEGER,value TEXT);
```

## Supplied application patch

```sql
DELETE FROM migrated WHERE id IN (SELECT entity FROM work); INSERT INTO migrated SELECT * FROM (SELECT d.id,CASE WHEN EXISTS(SELECT 1 FROM edits e WHERE e.id=d.id) THEN (SELECT value FROM edits e WHERE e.id=d.id ORDER BY seq DESC LIMIT 1) WHEN d.present=1 THEN d.value ELSE f.value END,CASE WHEN EXISTS(SELECT 1 FROM edits e WHERE e.id=d.id) THEN 'operator' WHEN d.present=1 THEN 'stored' ELSE 'default' END,COALESCE((SELECT MAX(seq) FROM edits e WHERE e.id=d.id),0) FROM documents d JOIN defaults f ON f.epoch=d.epoch) WHERE id IN (SELECT entity FROM work);
```
